# Ayurvedic

Free old English copies of classic Ayurvedic books.

Each book has two kinds of files:

- **PDF**: the scanned book pages. You can search inside them.
- **TXT**: plain text that a computer read from the scans. It has some spelling mistakes, but it is easy to search.

### What each book is about

- **Charaka Samhita**: the most important book of Ayurveda. It is about general medicine: what causes disease, how to find it, how to treat it, food, daily habits and herbs.
- **Sushruta Samhita**: the second big book. It is about surgery, plus many treatments.
- **The Materia Medica of the Hindus**: herbs and medicines, and what they are used for.
